# Expense-Tracker

A production SwiftUI expense tracking app using Spec-Driven Development (SDD).

## Tech Stack
- SwiftUI + Swift
- Clean Architecture with Coordinator pattern
- SwiftData for persistence
- Swift Testing + TDD
- OpenSpec workflow

## Getting Started
1. Clone the repo
2. Open in Xcode
3. Run tests: `swift test`
4. Build and run
